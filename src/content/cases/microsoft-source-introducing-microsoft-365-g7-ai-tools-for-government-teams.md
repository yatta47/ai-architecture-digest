## 概要

Microsoftは政府機関のGCC環境向けにMicrosoft 365 G7とAgent 365を発表し、生産性・AI・エージェント・セキュリティ・ID・コンプライアンス・ガバナンスを一つのスイートに統合した。Work IQで組織データに根ざしたCopilot体験を提供する一方、Agent 365をエージェントの発見・登録・権限管理・ライフサイクル統制のための制御プレーンと位置づけ、実験的なAI導入から組織規模での統制されたAI活用への移行を支援する。

## 設計のポイント

- Work IQを介してCopilotの応答を組織データ・コンテキスト・権限に紐づけ、根拠のある回答を可能にする
- Agent BuilderやCopilot Studioにより、業務担当者自身がミッション特化型エージェントを構築できるようにする
- Agent 365をエージェント専用の制御プレーンとして分離し、発見・登録・ブロック・削除などのガバナンス操作を一元化する
- 段階的なGCC認証マイルストーンに合わせて機能を順次展開し、規制要件を満たしながら先行導入できるようにする

## 使いどころ

- AI活用を組織全体で統制しながら拡大したい政府機関のIT・セキュリティ部門
- ケース管理・助成金審査・住民対応など専門業務でエージェントを構築したい現場チーム
- どのエージェントが存在し何にアクセスしているかを可視化・統制したいリーダー層
