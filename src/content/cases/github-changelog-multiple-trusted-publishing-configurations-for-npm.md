## 概要

npmパッケージのtrusted publishing(OIDC)機能がパッケージごとに複数設定できるようになり、ステージ済みパッケージはマルウェアスキャン完了後にのみ承認可能になるなど、サプライチェーンセキュリティを強化するアップデートがGAになったことを紹介する。
