## 概要

GitHub Copilotは2026年12月14日に複数モデルを全体験で廃止し、Claude Fable 5.2、Haiku 5.5、Gemini 4 Hydrogen等への移行を案内した。EnterpriseとBusinessでは代替モデルが既定で自動有効化される。
