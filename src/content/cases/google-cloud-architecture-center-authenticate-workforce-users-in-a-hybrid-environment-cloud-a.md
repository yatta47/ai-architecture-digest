## 概要

オンプレミスのMicrosoft Active Directory Domain Services（AD DS）などの既存アイデンティティ管理をGoogle Cloudへ拡張し、従業員がハイブリッド環境全体でシングルなアイデンティティ管理のもとに安全に認証・サービス利用できるようにする設計ガイドの第1部。統合アイデンティティ管理を維持しながらGoogle Cloudと連携する方法を扱う。
