## 概要

Oracle E-Business Suite・PeopleSoft・その他エンタープライズアプリを、Oracle Database on Compute EngineまたはOracle Exadataと組み合わせてGoogle Cloud上で動かすための参照アーキテクチャの一覧ページ。アプリケーションとデータベースの組み合わせを選ぶと該当する構成ガイドに遷移する。
