## 概要

GitHub ClassroomはWebサイト・API・関連サービスが正式に廃止され、選定パートナーソリューションへの移行が完了した。既存のGitHubユーザーアカウント・リポジトリ・組織自体は影響を受けないが、クラスルーム名や外部リポジトリで定義されていないテストなど一部のClassroom固有データはデータ保持ポリシーに従い削除される。
