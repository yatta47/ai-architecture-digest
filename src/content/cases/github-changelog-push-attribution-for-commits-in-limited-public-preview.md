## 概要

GitHubが各コミットに認証済みのプッシュ者を恒久的に記録し、UIとAPIで表示する機能をEnterprise向けに限定公開した。新しいルール条件『Committer must match pusher』で、コミッターのメタデータがプッシュ者の検証済みメールと一致しないプッシュを遮断し、なりすましを防ぐ。
