## 概要

ホスピタリティ向けCDPを提供するRevinateは、宿泊施設やパートナーへゲスト情報を公開するAPI基盤にAmazon API GatewayとAPI Gateway Portalを採用した。従量課金の利用と消費者別のコスト配分により、オンボーディングと運用負荷が改善された。
