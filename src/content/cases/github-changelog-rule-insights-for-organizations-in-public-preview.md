## 概要

GitHubが組織レベルのRule Insightsダッシュボードをパブリックプレビューで提供開始。組織内の全リポジトリのルールセット評価状況を一箇所に集約し、バイパスの多いリポジトリの特定やCSVエクスポートによるガバナンス報告を容易にする。
