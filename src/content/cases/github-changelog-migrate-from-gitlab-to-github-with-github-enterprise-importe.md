## 概要

GitHub Enterprise Importer(GEI)を使い、gitlab.comおよびGitLab Self-Managedの現行バージョンからGitHub Enterprise Cloudへリポジトリを移行できる機能が一般提供開始となった。gh gl2gh CLI拡張により単一リポジトリ移行やスクリプトによる一括移行をセルフサービスで実行でき、移行アーカイブはGitHub所有のBlobストレージまたは自社のAWS S3・Azure Blobストレージに保存できる。対象はgithub.comおよびghe.com上のGitHub Enterprise Cloud組織で、GitHub Enterprise Serverへの移行は非対応。
