## 概要

2026年10月1日以降、GitHub Actionsのチェック・ワークフロー実行・ステータスは、これまで400日以上保持されていたのをやめ、アーティファクトやログと同じ保持期間設定に従って自動削除されるようになる。保持期間を延ばすと課金対象のActionsストレージ使用量が増える可能性があるため、事前に設定の見直しとエクスポートが推奨される。
