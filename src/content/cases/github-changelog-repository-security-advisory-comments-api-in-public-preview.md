## 概要

リポジトリセキュリティアドバイザリのコメントを一覧、取得、追加、編集できるREST APIがパブリックプレビューで提供された。監査や移行のための議論エクスポートや、トリアージメモの自動追加などに使える。機密コメントは返されず、削除は未対応。
