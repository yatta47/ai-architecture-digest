## 概要

OPC Foundation Cloud Initiativeの参照アーキテクチャに基づき、OPC UA標準でショップフロアのテレメトリをAzureの分析サービスへ接続する構成を示す。状態監視やOEE分析、異常検知といったユースケースをベンダーロックインなしで実現するための前提条件・権限設定・STRIDE脅威分析までを網羅する。
