## 概要

VMware Engineワークロード向けに、Cloud MarketplaceのネットワークアプライアンスとCloud Load Balancingを組み合わせてDDoS対策・NGFW・IPS/IDS・SSLオフロードなどのディフェンスインデプス機能を提供するアーキテクチャ。公開ワークロード保護・オンプレミス通信保護・集中egressなど複数の利用シナリオを扱う。
