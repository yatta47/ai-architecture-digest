## 概要

GitHub Enterprise Server 3.22リリース候補では、エア・ギャップ環境向けCopilot CLIのモデルプロバイダ設定(技術プレビュー)に加え、Enterprise Teamsによる一元的なアクセス管理のGA、シークレットスキャン申請の並べ替え、リポジトリルールセットのユーザー単位バイパス、必須レビュアールールなどが追加された。
