## 概要

GitHub Enterprise Cloudでのセルフホストランナー最低バージョン要件の強制開始日が2026年9月29日に変更された。2.329.0未満のランナーは登録できず、下限未満のランナーはジョブ実行も止まるため、アップグレードが必要。
