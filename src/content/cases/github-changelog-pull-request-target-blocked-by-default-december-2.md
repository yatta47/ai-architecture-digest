## 概要

GitHub Actionsは2026年12月2日から、公開リポジトリでpull_request_targetをポリシーで許可しない限り既定でブロックする。11月9日と16日にブラウンアウトがあり、フォークの不審コードによるシークレット漏えいを防ぐ。
