## 概要

GitHub Actionsにランナーバージョンの非推奨時期を取得するREST API、GITHUB_TOKENへのvulnerability-alerts読み取り専用権限、再利用可能ワークフロー向けの新しいjobコンテキストプロパティが追加され、可視性と最小権限での制御が強化された。
