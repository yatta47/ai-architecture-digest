## 概要

100%の可用性を目指すのではなく、ユーザーが満足する『十分な信頼性』の水準を見極め、コストとのバランスで現実的な目標を設定することを推奨。99.99%稼働率などの目標とエラーバジェットの考え方、RTO/RPOを踏まえたコストベネフィット分析を解説する。
