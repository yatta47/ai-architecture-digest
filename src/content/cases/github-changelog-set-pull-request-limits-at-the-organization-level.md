## 概要

GitHubは、書き込み権限のないユーザーが同時に開けるプルリクエスト数の上限を、リポジトリ単位だけでなく組織単位でも一括設定できるようにした。組織の設定からInteraction limitsでプルリクエスト上限を定義することで、多数のリポジトリを管理するメンテナーの運用負荷を減らせる。
