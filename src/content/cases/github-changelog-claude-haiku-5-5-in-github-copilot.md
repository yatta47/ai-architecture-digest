## 概要

軽量モデルClaude Haiku 5.5がCopilotで一般提供。サブエージェントや簡単な編集向けで、初期検証ではSonnet 5と同等の多くのコーディング作業をより少ないトークンで処理した。

## 設計のポイント

- 軽量モデルをサブエージェント用途に当てる。
- 管理者がモデルポリシーでアクセスを制御できる。

## 使いどころ

- Copilotの利用コストを抑えたい組織に効く。
