## 概要

個人アカウント所有のリポジトリで、プルリクエストやIssueのコメントメニューから直接ユーザーをブロック/ブロック解除できるようになった。理由を記録する非公開メモも付けられ、スパムや迷惑行為への対応をページ移動なしで行える。
