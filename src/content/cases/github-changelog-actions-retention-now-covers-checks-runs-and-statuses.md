## 概要

GitHub Actionsの保持期間設定が、アーティファクトとログに加えてチェック、ワークフロー実行、ステータスにも適用されるようになった。期間超過分は自動削除され、公開リポジトリの上限は90日で、削除済みデータは復元されない。
