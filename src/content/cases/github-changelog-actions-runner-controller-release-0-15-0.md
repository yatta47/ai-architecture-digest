## 概要

GitHub Actions Runner Controller 0.15.0は、ランナースケールセットの信頼性、スケーラビリティ、可観測性を改善した。パッチ更新の in-place 化、設定可能なシャットダウン猶予、更新のpatch化、同時実行数やレート制限の設定などにより、大規模ランナー群を中断少なく運用できる。
