## 概要

GitHubは依存関係グラフのライセンス情報の主要ソースを、ClearlyDefinedによるファイルスキャンからnpmjs.orgやPyPIなど各パッケージレジストリのメタデータ優先に切り替えた。170万パッケージ中ライセンス欠落率が45%から24%に半減し、SBOMやライセンスコンプライアンス機能、Dependabotのレビューの精度が向上した。
