## 概要

GitHubのコードスキャニングに、脆弱性自体はコードに残るがWAFやネットワークポリシーなど外部の統制でリスクを緩和している場合に使う却下理由『Mitigated』が追加された。Won't fixとの区別を明確にし、正式な例外/リスク受容プロセスとの整合、GitHub外部での追跡の手間削減につながる。
