## 概要

2026年12月1日から1週間かけてGitHub.comの通知仕様を移行する。手動で購読解除した後は通常のコメント等で再購読されず、通知理由は優先順位で決まり、メールヘッダには全理由が含まれる。通知理由でフィルタや自動化をしている場合は見直しが必要。
