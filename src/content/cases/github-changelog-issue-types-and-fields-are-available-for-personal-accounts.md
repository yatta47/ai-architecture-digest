## 概要

Issueタイプ(最大25種)とIssueフィールド(最大25種)が、個人アカウント所有のリポジトリでも一般提供された。設定画面でカスタマイズでき、プロジェクトのビューや一括更新、API・Webhookでの自動化に使える。
