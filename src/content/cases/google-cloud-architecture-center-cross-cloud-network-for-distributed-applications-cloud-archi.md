## 概要

複数のクラウドおよびオンプレミス環境にまたがる分散アプリケーションを、単一クラウドのような開発・運用体験で構築できるようにするCross-Cloud Networkのアーキテクチャ設計ガイド序文。ネットワークセグメンテーション、サービスネットワーキング、ネットワークセキュリティという3つの機能レイヤーで構成を支える4部構成シリーズの入り口。
