## 概要

GitHubは、既存のブランチ保護ルールをリポジトリ設定から1クリックでリポジトリルールセットに変換できる機能を追加した。必須レビューやステータスチェック、プッシュ制限が等価なルールセットのルールへ自動的にマッピングされ、手作業での再構築なしにより柔軟なガバナンス基盤へ移行できる。
