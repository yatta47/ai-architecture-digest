Claude Fable 5.2がGitHub Copilotで一般提供された。複雑なコーディングタスクで少ない手順で解決する。安全分類器のためデータ保持が既定で必要で、管理者のポリシー有効化が要る。

## 設計のポイント

- データ保持の要件を管理者ポリシーで明示的に有効化させる。
