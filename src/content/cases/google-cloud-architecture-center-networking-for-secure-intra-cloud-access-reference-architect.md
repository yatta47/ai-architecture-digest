## 概要

VPCネットワーク間・内のワークロードアクセスを保護するための参照アーキテクチャ集。Cloud Next Generation FirewallやネットワークタグによるファイングレインなFW制御、ネットワーク仮想アプライアンス、Cloud IDSによるトラフィック検査などの組み合わせを示す。
