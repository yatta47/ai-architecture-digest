## 概要

Visual Studio 2026を搭載したWindows 11 arm64イメージが標準・大規模GitHub-hostedランナーで一般提供された。2026年9月21日からwindows-11-armイメージが段階的にVS2026へ既定移行し、9月30日に完了予定。VS2022依存のワークフローは破壊的変更の影響を受ける可能性がある。
