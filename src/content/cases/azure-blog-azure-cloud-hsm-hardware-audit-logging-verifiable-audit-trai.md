## 概要

Azure Cloud HSMがHSM自体が生成する監査記録を収集するハードウェア監査ログを発表。認証、ユーザー管理、ポリシー変更、鍵ライフサイクル、バックアップなどの操作を対象とし、署名済みバイナリと証明書により利用者が独立に真正性を検証できる。AI関連ではないセキュリティ機能の告知。
