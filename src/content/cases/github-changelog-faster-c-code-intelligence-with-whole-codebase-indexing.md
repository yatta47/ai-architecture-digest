## 概要

Copilot CLIのC++コードインテリジェンスで、Microsoft C++ Language Serverが全コードベースのシンボルの永続インデックスを作る機能が既定で有効になった。定義や参照の検索が速くなり、初回構築時のみ時間とメモリが増える。
