## 概要

GitHubコードスキャンのAI Scan for repositoriesを、組織・リポジトリ単位でREST APIから有効化/無効化できるようになった(パブリックプレビュー)。repository_scan設定が追加され、pr_scanと同時更新も可能で、片方が失敗すると両方とも変更されない。
