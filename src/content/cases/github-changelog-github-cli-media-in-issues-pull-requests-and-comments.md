## 概要

GitHub CLI（gh）に、ローカルの画像や動画をアップロードしてIssue・プルリクエスト・コメント本文にインラインで参照できる、繰り返し指定可能な--attachフラグが追加され、全プランで一般提供された。既存のMarkdown内のローカルパス参照はアップロード済みアセットへ自動的に書き換えられ、これまでブラウザ操作が必要だった画像添付をコマンドラインだけで完結できるようになった。
