## 概要

GitHubは、個人アカウントが所有するリポジトリのDiscussionコメントから直接ユーザーをブロック・ブロック解除できる機能を追加した。Issueやプルリクエストのコメントで既に提供されていたインコンテキストのブロック操作をDiscussionにも拡張するもので、ブロック時には理由を説明する非公開メモを添えられる。
