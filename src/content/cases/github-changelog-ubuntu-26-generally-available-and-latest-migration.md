## 概要

GitHub ActionsのUbuntu 26.04ランナーイメージがパブリックプレビューを終え、x64/arm64双方で本番ワークフローに正式対応した。ubuntu-latestラベルは2026年10月19日から11月19日にかけて段階的にUbuntu 24.04から26.04へ移行される。ツールバージョンの変更により既存ワークフローが壊れる可能性があるため、事前検証とubuntu-24.04への固定が推奨されている。
