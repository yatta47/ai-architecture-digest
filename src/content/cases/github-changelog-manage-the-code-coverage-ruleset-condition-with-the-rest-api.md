## 概要

GitHubは、リポジトリのコードカバレッジ制約（最低カバレッジ率やカバレッジ低下の許容範囲）をREST API経由で作成・更新・参照できるようにした。従来はWeb UIでの設定が必須だったが、Infrastructure as Codeのワークフローに組み込み、多数のリポジトリで一貫してカバレッジ要件を管理できるようになる。
