## 概要

認証強度・デバイスの状態・ネットワーク位置などのコンテキストに基づいてアクセスを制御するcontext-aware accessの適用方法を解説する。Access Context Managerでアクセスレベルを定義し、Google Workspaceアプリ、Google Cloudコンソール・API、VPCサービスペリメータ、IAPなど対象ごとに適用する方法を示す。
