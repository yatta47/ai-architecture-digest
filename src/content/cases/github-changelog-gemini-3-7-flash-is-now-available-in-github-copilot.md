## 概要

GoogleのGemini 3.7 FlashがGitHub Copilotのモデルピッカーに追加された。Web/アプリ開発やエージェント型コーディング、コード品質・最終出力の提示・コードベース調査で前バージョンから改善しているとされ、従量課金の標準価格で提供される。

## 設計のポイント

- Enterprise/BusinessプランはPreviewポリシーを個別に有効化しないと組織内で選択できない

## 使いどころ

- エージェント型コーディングやコードベース調査を行うタスクで軽量・高速なモデルを選びたい開発者
