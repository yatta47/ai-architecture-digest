## 概要

GitHubは個人アカウントおよびOrganizationのブロックユーザー管理機能を強化した。ユーザー名・氏名・メールでの検索、長いリストのソート・ページネーション、ブロック理由（スパム・不正行為・ハラスメント等）でのフィルタ、モデレーション文脈を残すための非公開メモ追加、誰がいつブロックを適用したかの表示ができるようになった。検索画面と新規ブロック画面を明確に分離し、誤ブロックを防ぎやすくしている。
