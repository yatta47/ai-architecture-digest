## 概要

GitHub Copilotのプラグインマーケットプレイスに対し、enterprise managed settingsでautoUpdate: trueを設定することで個別マーケットプレイスを自動更新対象にできるようになった。Copilot Business/EnterpriseのCopilotアプリ・CLI・VS Codeで利用でき、組織カスタマイズの保守作業を減らす。
