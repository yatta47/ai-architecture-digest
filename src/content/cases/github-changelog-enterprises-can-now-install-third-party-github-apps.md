## 概要

GitHub Enterpriseのオーナーは、エンタープライズ外部で作成された公開GitHub Appsを自組織のエンタープライズアカウントにインストールできるようになった。エンタープライズ権限を持つアプリは組織・リポジトリへのアクセスを持たず、境界をまたぐ強力な権限のアプリはクロスインストールを禁止するなど安全策が設けられている。
