## 概要

OpenAIのGPT-6.1 TerraがGitHub Copilotで一般提供となった。日常的なエージェントコーディングやターミナル作業向けで、GPT-6.1 Solより低コストである。管理者はモデルポリシーで有効化を制御できる。

## 設計のポイント

- 用途に応じて低コストモデルを選べる。
- 管理者がモデルポリシーで利用可否を管理する。

## 使いどころ

- Copilotで低コストなモデルを使い分けたい開発者。
- 組織のモデル利用を管理したい管理者。
