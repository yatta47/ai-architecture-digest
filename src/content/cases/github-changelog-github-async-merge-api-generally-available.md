## 概要

GitHubの非同期マージAPIが一般提供になった。個別・スタックPRのマージ、マージキュー追加、直接マージを非同期に処理し、権限があればルールのバイパスも可能。PUTで要求を送り、返されたIDでGETしてステータスを確認する。
