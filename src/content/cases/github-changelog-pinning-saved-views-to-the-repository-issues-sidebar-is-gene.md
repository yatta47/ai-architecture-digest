## 概要

リポジトリのIssuesサイドバーによく使う保存ビューをピン留めできるようになり、サイドバーを折りたたんでいてもワンクリックでアクセスできる。あわせてリアクションのアバター表示、Issues Dashboardの密度調整、クローズ済みサブIssueの非表示、Issue依存関係APIのスコープベースのフィルタリングも追加された。
