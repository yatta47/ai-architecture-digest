## 概要

GitHubはエンタープライズ管理者がGitHub Advanced Securityの設定を組織・リポジトリレベルの管理者による変更から強制的に保護できるようにした。従来はリポジトリ所有者による変更のみを防止していたが、新たに組織所有者による上書きも「強制」ドロップダウンから選択して禁止できるようになり、セキュリティ・コンプライアンスチームが一貫したポリシーを適用しやすくなった。
