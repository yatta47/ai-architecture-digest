## 概要

GitHubは個人ユーザー単位のCopilot予算に有効期限を設定できる機能を一般提供した。期限到来時に予算は自動的に削除され、ユーザーはコストセンター予算や全体予算にフォールバックする。従来は一時的な予算上書きを手動で削除する必要があり、エンタープライズ規模では継続的な運用負荷になっていた。
