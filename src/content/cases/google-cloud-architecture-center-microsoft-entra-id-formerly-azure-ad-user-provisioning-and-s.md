## 概要

Microsoft Entra IDテナントとCloud Identity/Google Workspaceアカウントの間で、ユーザーおよびグループの自動プロビジョニングとSAMLベースのシングルサインオンを設定する実践的な手順書。プロビジョニング専用ユーザーの作成と権限付与(スーパー管理者または委任管理者)、ドメイン登録など、Google管理コンソール上での具体的な設定ステップを解説している。
