## 概要

2026年6月1〜13日、SCIMでデプロビジョニングされた約12,285件のEnterprise Managed Userアカウントが、停止・難読化ではなく誤って削除された。新しい経路でEMUかどうかの確認が漏れていたのが原因で、経路を無効化し、コード修正と10月のアカウント復元を行った。
