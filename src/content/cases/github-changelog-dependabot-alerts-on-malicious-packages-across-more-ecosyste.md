## 概要

GitHub Advisory DatabaseがOpenSSFのmalicious-packagesリポジトリからマルウェア情報を自動取り込みするようになり、npmやPyPIなど対応エコシステムが拡大した。マルウェアアラートを有効化済みのユーザーは追加設定なしで恩恵を受ける。
