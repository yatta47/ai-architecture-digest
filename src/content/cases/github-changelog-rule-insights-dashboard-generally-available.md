## 概要

GitHubのルールインサイトダッシュボードがリポジトリ単位・組織単位の両方でGA提供された。ルールセットの成功・失敗・バイパスの推移を可視化し、CSVエクスポートにも対応することで、ガバナンス・コンプライアンス報告を手作業のデータ突き合わせなしで行えるようにする。
