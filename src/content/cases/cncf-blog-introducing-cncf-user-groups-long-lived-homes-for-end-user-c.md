## 概要

CNCFのEnd User CommunityがKubeConでUser Groupプログラムを開始した。業界や課題領域ごとの長期グループで、TABに直接報告し、憲章・月次公開会議・定期報告を義務とする。Technical Community Groupからの昇格経路も示している。
