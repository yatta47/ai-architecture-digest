## 概要

Cloud Run functions（第2世代）をShared VPC、Serverless VPC Access、VPC Service Controls、Cloud KMS、Secret Managerなどと組み合わせて保護するセキュリティブループリントを解説する。サーバーレスアプリケーションの重大リスク12項目に対応する設計とTerraform構成を提供する。
