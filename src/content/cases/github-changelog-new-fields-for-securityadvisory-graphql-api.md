## 概要

GitHubのGraphQL APIでSecurityAdvisoryにcveIdなど5つのフィールドが追加され、securityAdvisoriesクエリにseveritiesとisWithdrawnのフィルタが加わった。REST APIに頼らず助言データを読め、変更は追加のみで既存クエリに影響しない。
