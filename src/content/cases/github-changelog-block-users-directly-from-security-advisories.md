## 概要

GitHubのセキュリティアドバイザリページから、設定画面に移動せず三点メニューで直接ユーザーをブロックできるようになった。組織所有リポジトリではモデレーターまたは管理者が、個人所有リポジトリではオーナーが実行でき、アドバイザリ内容を保ったままスパムや荒らしの発生源だけを排除できる。
