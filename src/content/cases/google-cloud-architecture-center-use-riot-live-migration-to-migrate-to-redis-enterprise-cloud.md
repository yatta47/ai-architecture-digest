## 概要

Redis OSS・AWS ElastiCache・Azure Cache for Redisなど互換ソースから、フルマネージドのRedis Enterprise Cloudへ無停止で移行するためのRIOT Live Migrationの参照アーキテクチャ。RDBスナップショットなど他の移行方式との比較も示す。
