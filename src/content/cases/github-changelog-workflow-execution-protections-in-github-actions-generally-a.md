## 概要

GitHub Actionsのワークフロー実行保護機能が一般提供となり、誰がワークフローを起動できるか（アクタールール）とどのイベントで起動できるか（イベントルール）を許可リストとして定義できる。ワークフローファイル単位でのスコープ指定、影響を事前確認できる評価モード、REST APIによるポリシーのコード管理に加え、pull_request_targetの悪用（Pwn Requests）を防ぐ既定保護ルールがパブリックリポジトリに順次導入される。
