## 概要

GitHubのSCIMユーザーレスポンスに、RFC 7643で定義される標準のprofileUrl属性が追加され、外部IDに紐づくGitHubアカウントの絶対URLを直接取得できるようになった。これまで必要だった追加のルックアップや推測作業なしに、IDプロバイダやITチームがSCIMレコードとGitHubアカウントを突合できる。既存の統合には影響しない追加的変更。
