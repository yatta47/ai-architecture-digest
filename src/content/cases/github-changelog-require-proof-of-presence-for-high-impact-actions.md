## 概要

GitHub Enterprise Cloudで、トークン作成やWebhook編集などの高影響操作の前にIdPでの再認証またはMFAを要求できる公開プレビューを開始した。盗まれたセッションやトークン、乗っ取られたエージェントによる操作を防ぎ、EntraのEMU企業が対象となる。
