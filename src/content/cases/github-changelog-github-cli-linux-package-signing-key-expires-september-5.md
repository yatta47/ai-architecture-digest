## 概要

GitHub CLIのLinuxパッケージ(APT/RPM)向けPGP署名鍵が2026年9月5日に失効するため、置き換え鍵への信頼設定を促す注意喚起。2026年4月8日以前にリポジトリからインストールし設定を更新していないユーザーは対応が必要。
