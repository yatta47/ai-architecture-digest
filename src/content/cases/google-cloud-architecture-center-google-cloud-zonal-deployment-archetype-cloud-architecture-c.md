## 概要

アプリケーションを単一ゾーンで稼働させる「ゾーン配置アーキタイプ」を解説する文書。デュアルゾーン構成によるフェイルオーバーの仕組みや、開発・テスト環境やライセンス制約のあるソフトウェアなど適切なユースケースを紹介している。
