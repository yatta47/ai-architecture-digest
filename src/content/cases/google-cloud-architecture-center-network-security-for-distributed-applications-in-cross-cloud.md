## 概要

Cross-Cloud Network設計ガイドのうち、ネットワークセキュリティレイヤーを扱うパート。ワークロード間・VPC内外の通信を守るワークロードセキュリティと、組織間ネットワーク境界を守るドメインペリメータセキュリティという2つのセキュリティサーフェスを軸に、Cloud Next Generation Firewallなどによる実装方針を解説する。
