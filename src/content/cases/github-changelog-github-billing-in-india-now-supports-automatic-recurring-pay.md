## 概要

インドの顧客は、対象となる保存済みクレジットカードを使って月次・年次のGitHub請求を自動継続支払いできるようになった。インド準備銀行(RBI)の要件に沿った決済マンデート(電子マンデート)を用いて将来の請求を許可する仕組みで、支払い方法の保存・削除方法自体は変更されていない。
