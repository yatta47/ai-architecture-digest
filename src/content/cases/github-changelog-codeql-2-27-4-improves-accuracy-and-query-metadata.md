## 概要

CodeQL 2.27.4は、Java/Kotlin・Rust・C/C++のクエリで誤検知を減らし、ReDoS系クエリのCWE-730タグを外す。パック作成時にシンボリックリンク先がルート外のファイルを除外する検査も加わった。
