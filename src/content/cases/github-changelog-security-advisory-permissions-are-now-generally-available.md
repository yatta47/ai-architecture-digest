## 概要

GitHubで、リポジトリのカスタムロールにセキュリティアドバイザリ関連の4つの権限が追加された。管理者権限を与えずに、アドバイザリや非公開の脆弱性報告を扱う権限を必要なリポジトリだけに付与できる。
