## 概要

GitHubの公開モニタリングに、アラートの却下・再開、タイムライン、フィルタ、トークン有効性の常時チェックが追加された。REST APIとエンタープライズWebhookで検知結果をインシデント対応に連携できる。GitHub Enterprise Cloudでパブリックプレビュー中。
