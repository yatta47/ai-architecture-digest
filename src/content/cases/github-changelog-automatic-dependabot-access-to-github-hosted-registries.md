## 概要

DependabotのGITHUB_TOKENがpackages: read権限をリクエストできるようになり、Manage Actions accessでリポジトリに許可されたプライベートGitHub Packagesレジストリ（*.pkg.github.com、ghcr.io）に個人アクセストークン無しでアクセスできるようになった。
