## 概要

SQL Server on Azure Local が接続環境・非接続環境の双方で一般提供となった。ソブリン要件や規制、エッジなどデータを外に出せない環境でSQL Serverを運用できる。Foundry Local on Azure Local（プレビュー）でデータの近くでAI推論を行う構想も示された。
