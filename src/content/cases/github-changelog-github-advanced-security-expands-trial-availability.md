## 概要

GitHub Advanced Securityのセルフサーブ試用の対象が、ライセンス数100までの企業からライセンス数300までの企業に拡大された。GitHub Enterprise Cloud顧客はコードスキャンとシークレット保護を、課金・ライセンスページから試用開始できる。
