## 概要

Anthropicの最新モデルClaude Opus 5.5がGitHub Copilotで利用可能になった。Opus 5と同等のタスク解決をより少ないステップとトークンで行い、テキスト出力にはウォーターマークが付く。

## 設計のポイント

- プロバイダーの定価による従量課金で提供される。
- 管理者がモデルポリシーでアクセスを制御できる。
- VS Code、Copilot CLI、coding agent等の複数の画面で選択できる。

## 使いどころ

- 長時間のエージェント型コーディングを行う開発者。
- 組織のモデル提供範囲を管理する管理者。
- モデル選択でコストと品質を調整したいチーム。
