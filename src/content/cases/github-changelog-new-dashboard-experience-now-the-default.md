## 概要

機能プレビューだった新しいGitHubダッシュボードが全ユーザーの既定ビューになった。アクティブなエージェントセッション、Issue、プルリクエストを一覧し、フィルターで各セクション最大12件を絞り込め、フィードは別タブに分かれた。Issueの割り当てやCopilot Chatでのプルリクエスト作成など、ダッシュボードから作業を始められ、従来表示にも戻せる。
