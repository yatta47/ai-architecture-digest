## 概要

GitHub Code Qualityでリポジトリの有効化・無効化・設定変更が発生すると、repo.code_quality_enabled/disabled/updatedという3種類の監査ログイベントが記録されるようになった。課金がアクティブなコミッター数で決まるため、いつリポジトリが課金対象に入退したかを正確に追跡できる。
