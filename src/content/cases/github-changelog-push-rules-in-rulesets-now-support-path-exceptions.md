## 概要

GitHubのルールセットにおけるプッシュルール（ファイルパス制限・ファイルサイズ制限）が、特定パスを例外として除外できるようになった。ルール全体を緩めたりGitHub外で運用したりせずに、必要な箇所だけ例外を許容できる。
