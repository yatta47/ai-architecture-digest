## 概要

GitHubのコードスキャン既定セットアップに、リポジトリプロパティ経由でカスタムCodeQL設定ファイルを適用できるようになった。組織全体で一元管理しつつ、リポジトリごとの上書き許可やプライベートリポジトリからの設定参照にも対応する。
