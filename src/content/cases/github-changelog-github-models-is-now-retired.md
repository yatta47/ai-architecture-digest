## 概要

GitHub Modelsのプレイグラウンド・モデルカタログ・推論API・BYOKが2026年7月30日付けで完全終了。既存ユーザーを含め全顧客が利用できなくなり、移行先としてMicrosoft FoundryのモデルカタログやGitHub Copilotが案内されている。
