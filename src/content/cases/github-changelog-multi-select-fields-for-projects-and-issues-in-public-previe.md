## 概要

GitHub ProjectsとIssue Fieldsで、1つのフィールドに複数の値を設定できるマルチセレクト型フィールドがパブリックプレビューで提供開始された。複数チームやモジュールにまたがるアイテムに単一フィールドでタグ付けし、ビューでフィルタできる。
