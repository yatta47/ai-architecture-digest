## 概要

CodeQL CLI 2.27.0以降、全プラットフォームの実行バイナリを同梱したcodeql-bundleが非推奨となり、2027年3月頃に廃止される予定。今後はOS・アーキテクチャ別のプラットフォーム固有バンドルをダウンロードする必要があり、Linux ARM64はプラットフォーム別配布でのみ提供される。
