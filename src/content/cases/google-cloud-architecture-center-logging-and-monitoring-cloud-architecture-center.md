## 概要

Google Cloud Observability for GKEとPrometheus互換のマネージドサービスを使い、プラットフォームチームとテナントごとにログ・メトリクスのアクセス範囲を分離する設計を解説する。Security Command CenterによるコンテナやWeb脆弱性の脅威監視についても触れる。
