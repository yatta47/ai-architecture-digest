## 概要

GitHubが個々のスターを付けたユーザーの情報を公開せずにリポジトリのスター数推移をタイムスタンプ付きで取得できる新しいREST APIエンドポイントを公開した。スターギャザー一覧APIが管理者・共同作業者限定に制限されて以降失われていたスター推移の追跡を、プライバシーに配慮した形で復元する。
