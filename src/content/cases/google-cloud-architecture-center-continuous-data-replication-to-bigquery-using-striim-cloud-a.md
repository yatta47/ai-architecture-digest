## 概要

パートナー企業StriimによるチュートリアルでCloud SQL for MySQLをソースにBigQueryへ継続的にストリーミングレプリケーションする方法を解説する。オンプレミスや他システムのトランザクションデータをGoogle Cloudの分析基盤へ移行・複製する実装例として提供されている。
