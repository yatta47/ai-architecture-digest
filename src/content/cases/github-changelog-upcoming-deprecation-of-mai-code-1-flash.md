## 概要

GitHubは、後継のMAI-Code-1.1-Flashのリリースに伴い、旧モデルMAI-Code-1-FlashをすべてのCopilot体験から2026年9月10日に廃止すると発表した。Enterprise管理者は廃止日までにモデルポリシーで新モデルへのアクセスを有効化する必要があり、旧モデル廃止後の追加対応は不要とされる。

## 設計のポイント

- 新モデルのリリースと旧モデルの廃止日を明示し、約1カ月の周知期間を設けて計画的な移行を促した。
- Enterprise管理者がCopilotのモデルポリシーで新モデルへのアクセスを事前に有効化する運用手順にし、切り替え後の断絶を防いだ。

## 使いどころ

- Copilotの特定モデルにワークフローや連携を紐付けている企業が、廃止スケジュールに合わせて計画的に移行したい場合。
- 複数モデルのポリシーを一元管理するCopilot Enterprise管理者。
