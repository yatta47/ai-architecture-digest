## 概要

GitHub Teamの顧客が、GitHub Code SecurityとGitHub Secret Protectionを評価するためのGitHub Advanced Securityのセルフサービス試用を開始できるようになった。試用は組織のOverviewページ、Billing and licensingのLicensingページ、またはRisk Assessment完了ページから開始できる。
