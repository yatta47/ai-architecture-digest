## 概要

VMware vSphere・Microsoft Hyper-V・Nutanix AHVといったオンプレミス仮想化基盤から、Google Cloud VMware Engine・Compute Engine・Nutanix Cloud Cluster (NC2) のいずれに移行するかを選ぶための索引ページ。移行元と移行先の組み合わせごとに詳細ドキュメントへのリンクを整理している。
