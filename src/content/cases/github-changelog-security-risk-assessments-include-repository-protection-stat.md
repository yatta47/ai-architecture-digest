## 概要

GitHubのコードセキュリティ及びシークレットのリスク評価で、検出が保護済み・未保護どのリポジトリにあるかが表示されるようになった。Enterprise CloudとTeamで利用でき、Enterprise Server 3.24でもシークレット評価に対応予定。
