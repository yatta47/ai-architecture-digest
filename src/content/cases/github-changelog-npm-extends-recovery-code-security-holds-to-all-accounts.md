## 概要

npmは、リカバリコードでのサインイン成功後に72時間のセキュリティホールドを設ける保護を、従来の高インパクトアカウントだけでなく全アカウントに拡大した。ホールド中は公開などセキュリティに影響する書き込みが一時停止される。
