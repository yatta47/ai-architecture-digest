## 概要

CopilotエージェントセッションがSDKへ移行した一部のIDEで、利用指標にエージェント活動が計上されない問題が見つかった。VS Codeでは修正済みで、他のIDEも2026年11月までに順次配信される。課金への影響はなく、過去分の補正はできない。
