## 概要

GitHubは、ユーザーを個人アカウントまたは組織からブロックする際に、そのユーザーが作成したissue・discussion・pull requestを一括でクローズできるオプションを追加した。ブロックダイアログから選択でき、モデレーション対応の手間を削減する。
