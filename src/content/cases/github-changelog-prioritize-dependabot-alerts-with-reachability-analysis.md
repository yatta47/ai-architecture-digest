## 概要

DependabotにJavaScript/TypeScript向けの到達可能性解析(公開プレビュー)が加わり、CodeQLのコールグラフで脆弱な関数への呼び出し経路を調べ、アラートごとに判定を表示する。判定でアラートが自動的に閉じられることはない。
