## 概要

GitHubはCopilotのChat、インライン編集、エージェント、補完でGemini 3.7 Flash、GPT-5.5、GPT-5.4系、Grok 4.5を廃止し、後継モデルを案内した。Enterprise管理者は代替モデルのポリシーを有効化する必要がある。

## 設計のポイント

- モデル廃止は事前告知と後継の対応表で移行を促す。
- Enterpriseでは、代替モデルがポリシーで有効かを管理者が確認する必要がある。

## 使いどころ

- Copilotのモデル選択を管理するEnterprise管理者。
- 特定モデルに依存するワークフローを持つ開発チーム。
