## 概要

GitHubは、リポジトリ管理者がDependabotのバージョン/セキュリティ更新を実行するランナー種別・カスタムラベル・ランナーグループを設定できるようにした。ラベル付きランナーによりセルフホストや大型GitHubホストランナーを指定でき、プライベートパッケージレジストリへのアクセスなどに対応する。github.com上のプライベート/内部リポジトリが対象である。
