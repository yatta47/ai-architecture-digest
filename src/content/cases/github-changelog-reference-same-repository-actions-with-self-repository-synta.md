## 概要

GitHub Actionsに、同一リポジトリ内のアクションやReusable Workflowを実行中のコミットへ自動解決して参照できる新構文($/)を追加。従来の./参照+チェックアウトやバージョンのハードコードに伴うメンテナンス負荷とコミットSHA固定の形骸化を解消する。
