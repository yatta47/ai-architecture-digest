## 概要

データを「データプロダクト」として捉え、データを最もよく理解するドメインチームが組織横断のガバナンス基準に沿って開発・公開するデータメッシュの、中央サービスとデータドメインという主要な構成要素と役割を定義するシリーズ第1弾。
