## 概要

Power BIをAzure Data Explorerに接続し、OEEや生産数、エネルギー消費といった製造指標をKQLクエリで取得してインタラクティブなレポートを作成する手順を示す。モバイル閲覧や共有機能により、現場管理者や意思決定者が工場データにアクセスしやすくなる。
