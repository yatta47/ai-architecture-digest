## 概要

AzureがVMファミリーの提供状況を Current・Extended・End of Life・Retired の4段階で定義するライフサイクルポリシーを公表した。各段階での投資水準、可用性、購入オプションを明示し、顧客の移行計画を支援する。最初の対象は汎用・メモリ最適化・コンピューティング最適化・ストレージ最適化のVMファミリー。
