## 概要

Debian Linux VM上にChrome Remote Desktopサービスとxfce等のデスクトップ環境を導入し、ローカル端末からブラウザ経由でGUIアプリへリモートアクセスできるようにするチュートリアル。追加のファイアウォール設定は不要。
