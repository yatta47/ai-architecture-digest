## 概要

Claude Sonnet 5.5がGitHub Copilotで一般提供となった。機能実装やバグ修正といった範囲の明確な作業に向き、Sonnet 5と同等の性能を、より少ないステップ・トークン・ツール呼び出しで出せるという。管理者はモデルポリシーでアクセスを制御できる。

## 設計のポイント

- 新モデルは既定で有効になるが、管理者がポリシーで無効化できる。
- VS Code、CLI、コーディングエージェントなど複数の入口で同じモデルを選べる。
- 従量課金でプロバイダの定価が適用される。

## 使いどころ

- Copilotを組織展開する管理者。
- 日常的な実装・修正の効率とコストを両立したい開発者。
- モデルの提供範囲を統制したい企業のIT部門。
