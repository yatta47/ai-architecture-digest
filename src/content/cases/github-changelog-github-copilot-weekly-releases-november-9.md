## 概要

GitHub Copilotの週次更新で、新モデルの提供、GHESリポジトリの対応、MCPサーバーの再サインイン、プロジェクト自動化のスケジュール、VS Codeのエージェント関連機能が追加された。

## 設計のポイント

- MCPサーバーの再認証を会話内で完結させる。
- 新モデルはデータ保持などのポリシーを管理者が有効化する運用にする。

## 使いどころ

- Copilotを組織展開する管理者。
- エージェント機能を使う開発者。
