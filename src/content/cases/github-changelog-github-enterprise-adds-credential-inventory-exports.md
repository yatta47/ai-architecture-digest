## 概要

GitHub Enterpriseのオーナーが、SSHキーやパーソナルアクセストークン、OAuth Appトークンなどエンタープライズにアクセスできる全認証情報の一覧をCSVまたはREST API経由でエクスポートできるようになった。セキュリティインシデント発生時に侵害された可能性のあるトークンの範囲を素早く把握し対応計画を立てられる。
