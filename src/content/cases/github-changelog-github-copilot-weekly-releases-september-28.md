## 概要

Copilotに新モデルが追加され、モデルを自動選択するHydraFusion、再利用可能な動的ワークフロー、デスクトップアプリを操作するコンピューター操作が公開された。操作前の承認で利用者の制御を保つ。

## 設計のポイント

- 複数モデルをタスクに応じて選択・協調させる
- 手順を保存し、レビューで一時停止できるワークフローとして再利用する
- アプリ操作の前に承認を要求する

## 使いどころ

- 開発者がリリース確認や障害調査を繰り返し自動化する場面
- APIのないデスクトップアプリを含む業務を自動化する場面
