## 概要

MicrosoftのMAI Code 2（複雑な多ファイル実装向け）とMAI Code 2 Flash（軽量・低コスト向け）がGitHub Copilotで提供開始された。タスクの重さに応じて選べ、利用量課金で提供される。

## 設計のポイント

- 重い作業用と日常作業用の2モデルを使い分ける。

## 使いどころ

- タスクに応じてコストと能力を選びたい開発者。
