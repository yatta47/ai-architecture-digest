## 概要

GitHubはDependabotが作成するプルリクエストのブランチ名をカスタマイズできる新機能を発表した。.github/dependabot.ymlのpull-request-branch-name設定でプレフィックスや最大長、区切り文字、大文字小文字、カスタムテンプレートを指定できる。これによりCI/CDの命名規則や長さ制限への対応、モノレポでの識別性向上が図れる。
