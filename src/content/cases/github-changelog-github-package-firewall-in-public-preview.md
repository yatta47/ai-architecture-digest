## 概要

GitHubは、Actionsランナーやコーディングエージェントとアップストリームのレジストリのあいだでメタデータとダウンロードを検査するパッケージファイアウォールを、Enterprise Cloud向けにプレビュー公開した。クールダウン期間やAdvisory Database照合などをポリシーで設定する。
