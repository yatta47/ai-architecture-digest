## 概要

GitHubの組織レベルCode Qualityダッシュボードに、7/14/30日間の期間でオープンな指摘事項の増減を健全性スコアや深刻度別に追える「Trends」タブが追加された。改善が進むリポジトリと支援が必要なリポジトリをランキング表示し、既存のリポジトリフィルタと連動して対象を絞り込める。
