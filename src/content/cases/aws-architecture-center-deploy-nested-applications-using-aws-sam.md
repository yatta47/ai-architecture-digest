## 概要

AWS SAMのネストされたアプリケーション機能を使い、認証・商品・ショッピングという独立したCloudFormationスタックを親スタックから呼び出して構成するサーバーレスショッピングカートアプリの構築パターン。コンポーネントの再利用性とチーム間の一貫性向上を狙う。
