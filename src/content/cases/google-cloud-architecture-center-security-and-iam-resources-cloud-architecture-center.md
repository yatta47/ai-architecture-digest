## 概要

Google Cloud Architecture Centerが提供するセキュリティおよびIAM(アイデンティティ・アクセス管理)関連のドキュメント群を紹介するインデックスページ。エンタープライズ基盤のブループリントやIAMの概要、ランディングゾーン設計など、クラウド導入時のセキュリティ設計を学ぶための入り口となる資料を案内している。
